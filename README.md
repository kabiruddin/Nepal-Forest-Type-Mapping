Nepal Biophysical Forest Mapping (GEE)

This Google Earth Engine (GEE) script supports the development of subnational biophysical forest maps and indicators for Nepal.
It contributes to the analytical work featured in the World Bank report:
“May the Forest Be With You: Mapping Nepal’s Forest Landscapes and Livelihoods.”
